How it works

Three steps. No learning curve.

Designed to stay out of your way. Paste, pick a tone, and copy the result.

01 — Paste

Drop in your text

Paste up to 5,000 characters. Use the clear, paste, and live counts to stay in control.

02 — Choose

Select a mode

Professional, Casual, Humanize, AI Prompt, or Detector. Switch instantly with a single click.

03 — Copy

Transform and copy

Run with Ctrl + Enter and copy the result. The output preserves meaning, fixes tone.

Stack and API

Minimal dependencies. Ready to integrate.

Vanilla front end, single serverless endpoint, no heavy framework tax. Use the app or call the API directly.

Frontend — Vanilla HTML, CSS, and JavaScript. Dark-mode ready and fast by default.
Backend — Node.js Vercel Serverless Function at /api/transform.
Inference — GPT-OSS 120B via Groq. Set GROQ_API_KEY in Vercel or .env.local.
POST /api/transform
JSON 
Request
{
  "text": "String to be transformed",
  "tone": "professional | casual | humanize | prompt | detector"
}

Response
{
  "success": true,
  "text": "Transformed text here"
}
Content-Type: application/json CORS ready
